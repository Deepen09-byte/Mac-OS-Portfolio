# Mac-OS-Portfolio

A personal portfolio website styled as a fully interactive macOS desktop — complete with a dock, draggable windows, and a terminal you can actually type into.

## Tech Stack

- **Frontend:** React.js
- **Build tool:** Vite
- **Styling:** SCSS
- **Terminal emulation:** Custom terminal component (interactive CLI-style welcome experience)

## Features

- macOS-style desktop UI: dock, menu bar, draggable/resizable windows
- Interactive terminal emulator for a CLI-style intro/welcome experience
- Dock icons linking out to contact methods (mail, social, etc.)
- Multiple "apps" (windows) showcasing different sections of the portfolio (About, Projects, Contact, etc.)

## Getting Started

### Prerequisites

- Node.js v18+
- npm

### Installation

```bash
git clone https://github.com/Deepen09-byte/Mac-OS-Portfolio.git
cd Mac-OS-Portfolio
npm install
```

### Run locally

```bash
npm run dev
```

Vite will start a dev server, typically at `http://localhost:5173`.
